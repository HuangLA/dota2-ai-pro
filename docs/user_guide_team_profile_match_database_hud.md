# True Sight 普通用户操作指南（Match Database / Team Profile / HUD）

本文面向不看代码的普通用户，说明如何使用本阶段新增能力。

## 1. 启动方式

1. 启动后端服务（确保 `/health` 返回 `healthy`）。
2. 启动前端应用。
3. 打开首页，可看到 `比赛数据库`、`战队档案` 等入口。

---

## 2. Match Database 页面怎么用

入口：首页点击 `比赛数据库`

### 2.1 查询与筛选

- 可按 `team_id`、`leagueid`、时间区间、`has_download` 筛选。
- 新增 `仅职业联赛` 开关：默认开启（仅看职业联赛）；关闭后可查看全部比赛（含路人局）。
- 支持分页翻页（上一页/下一页）。
- 列表会显示比赛基础信息与下载状态。

### 2.2 单场动作

- `准备下载`：为该比赛创建/准备下载任务。
- `准备并执行`：准备并执行下载。
- `打开回放`：进入回放页面。
- `任务详情`：查看任务详情（状态、重试次数、错误码、错误信息、下载路径等）。

### 2.3 批量动作

- `批量准备（当前页）`：对当前页批量准备。
- `批量准备并执行（当前页）`：对当前页批量准备并执行。
- 完成后会显示 `Total/Success/Failed/withTaskId` 汇总。
- 可复制/导出失败清单（`复制失败项`、`导出失败项（.txt）`）。

### 2.4 状态与显示

- 下载状态有彩色徽章（pending/prepared/downloading/completed/failed）。
- 时间/时长为友好格式显示。
- 终态任务会停止自动刷新并显示终态提示。

---

## 3. Team Profile 页面怎么用

入口：首页点击 `战队档案`

### 3.1 基础查询

1. 输入 `team_id`（必填）。
2. 设置 `limit`。
3. 点击查询（或按页面默认触发方式加载）。

### 3.2 分组与筛选

- 比赛按赛事（league）分组展示，支持折叠/展开。
- 支持 `联赛快捷筛选` 快速切换某个赛事。
- 支持 `仅显示有下载状态`。
- 支持时间排序（最新优先/最旧优先）。
- 支持 `聚焦：最近联赛` 一键聚焦最近赛事。

### 3.3 页面级动作

- `准备当前可见比赛`：准备当前可见比赛。
- `在比赛数据库打开当前可见项`：带筛选上下文跳到比赛数据库。
- `导出可见比赛（.txt）`：导出当前可见比赛。
- `复制可见比赛 ID`：复制当前可见比赛 ID 列表。

### 3.4 League Compare（赛事对比）

- 显示 Top 赛事对比（场次、平均时长、最近比赛时间）。
- 点击行可快速应用赛事筛选。
- 支持多选赛事并 `应用已选联赛`。
- 支持 `准备已选联赛`、`导出对比选择（.txt）`。
- 支持 `打开对比首 3 场回放`（仅自动打开第一场回放）。
- 支持 `固定榜首联赛` 一键锁定对比第一名赛事。

### 3.5 快照（会话内）

- 支持保存最多 5 个命名快照。
- 支持 `保存快照/加载快照/应用快照/删除快照/清空全部快照`。
- 支持 `导入快照（.json）` 与 `导出快照（.json）`。

### 3.6 操作历史（Action History）

- 记录关键页面动作（最多 10 条）。
- 支持单条 `重放操作` 重放。
- 支持 `历史筛选`、`重放可见历史`、`重试`、`清除可见历史/清除全部历史`。

---

## 4. 回放页 HUD Metrics 怎么看

入口：从 Match Database 或 Team Profile 打开 Replay。

- 回放页新增 `HUD 指标` 面板。
- 显示每位英雄的：`Hero/Team/Lvl/K/D/A/NW/GPM/XPM`。
- 面板会跟随播放时间更新（内部有节流，不会过度请求）。
- HUD 请求失败时只影响 HUD 面板，不影响主回放。

---

## 5. 常见问题

### Q1: 为什么部分指标是 0 或空数组？

当前版本是“稳定契约优先”的第一版，部分字段先给 fallback（例如 items 为空），后续会继续补齐精度。

### Q2: 为什么某些按钮是灰色不可点？

通常是因为没有可操作目标（例如可见项为空、没有选择赛事、正在执行中）。

### Q3: 快照会永久保存吗？

不会。快照是“会话内”功能，重启前端后会消失。
