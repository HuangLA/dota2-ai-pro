TRUE SIGHT REDESIGN V2 / LIGHT + DARK ANALYST STUDIO

少一点控制台，多一点复盘室。

这版保留战术分析的专业感，但把硬边 HUD、密集网格和军用色调换成更安静的赛事分析桌。Dark 是雾面炭黑复盘室，Light 参考 macOS 的清爽玻璃感，两者都保留同一套功能密度。

双主题Dark 用于长时间复盘，Light 用于准备、筛选和会议讨论。
透明材质导航、顶栏、面板和地图浮层使用毛玻璃，不增加装饰噪声。
功能不删下载、解析、库、数据库、战队、地图、HUD、眼位都保留。

Recommendation

这版更适合作为 True Sight 的最终方向。

它没有上一版那么“硬”，但仍然保持专业和高信息密度。真正重构时，我建议把这套 Light / Dark 主题做进正式产品：主题可随时切换，地图复盘默认 Dark，准备室和会议演示优先 Light。

1Dark 保留现在这版的雾面炭黑，用于长时间盯地图和事件。
2Light 使用明亮玻璃和低饱和强调色，适合筛选、整理和会议展示。
3透明层只用于信息容器和浮层，避免为了玻璃效果牺牲可读性。
